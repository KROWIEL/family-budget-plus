# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-06

Первый публичный релиз.

### Возможности

- Два пользователя из конфига, вход без регистрации, профиль с аватаром, темой и валютой отчётов.
- Счета: источники дохода, карты, наличные, копилки с целью. Валюты BYN и USD.
- Операции: доход, расход, перевод, платёж по долгу. Ввод суммы в любой валюте с пересчётом по курсу НБРБ.
- Ручная правка суммы зачисления при переводах и платежах между валютами; сохраняется фактический курс.
- Категории трат с иконками, цветами, месячным лимитом и историей.
- Долги, кредиты и лизинги: остаток, ежемесячный платёж, день платежа, архив выплаченных, чистый капитал.
- Статистика за 1 / 3 / 6 / 12 месяцев, заканчивающаяся текущим месяцем: диаграмма по категориям,
  сравнение с прошлым периодом, разбивка по участникам, динамика накоплений.
- Курс НБРБ фиксируется на дату операции — статистика прошлых периодов не меняется вместе с курсом.
- Поиск и постраничный список операций.
- Резервная копия базы и восстановление из файла со старой схемой.
- Развёртывание одним `docker compose up`, автоматический HTTPS через Caddy.

### Безопасность

- Пароли хешируются через `scrypt`; md5-хеши ранних версий заменяются при входе.
- Ограничение неудачных попыток входа.
