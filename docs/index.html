Запуск за пару минут

Нужен только Docker. Для продакшена — домен: HTTPS настроится сам.

# локально
git clone https://github.com/KROWIEL/family-budget-plus.git
cd family-budget-plus
cp .env.example .env
docker compose -f docker-compose.local.yml up -d --build
# → http://localhost:8080

# на сервере с доменом и HTTPS
docker compose up -d --build
  1. Задайте пользователей. В .env — логины, имена и пароли двух участников. Регистрации нет.
  2. Для сервера укажите DOMAIN, ACME_EMAIL и COOKIE_SECURE=true, направьте A-запись на сервер.
  3. Запустите. Caddy получит сертификат Let's Encrypt, база SQLite будет лежать в ./data.
  4. Подробности — в README.
